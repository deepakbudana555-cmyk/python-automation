# Python Automation

A collection of practical Python automation scripts that simplify repetitive tasks and improve productivity.

## Features

- 📂 File Automation
- 📄 PDF Utilities
- 🖼 Image Processing
- 📊 CSV Automation
- 📁 Folder Management
- ⚡ Batch Processing

## Project Structure

```text
python-automation/
│
├── file-tools/
├── pdf-tools/
├── image-tools/
├── csv-tools/
├── folder-tools/
│
├── requirements.txt
├── README.md
└── LICENSE
```

## Requirements

- Python 3.10+
- pip

## Getting Started

```bash
git clone https://github.com/deepakbudana555-cmyk/python-automation.git

cd python-automation

pip install -r requirements.txt
```
